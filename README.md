##  Сапёр (Minesweeper)

Классическая игра "Сапёр" в неоновом киберпанк-стиле. Три уровня сложности, адаптивный дизайн и интеграция с ВКонтакте.

###  Скриншот

![Сапёр в ВКонтакте](screenshots/vk-minesweeper_gameplay.png)

### 🕹️ Как играть

- **ЛКМ** — открыть клетку
- **ПКМ** — поставить флажок 
- Цель: разминировать всё поле, не задев ни одной мины
